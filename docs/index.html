Your sources, your machine, your models.

Alchemy is a local-first research notebook for macOS. Import papers, repositories, folders, and links. Ask questions with citations, then create documents, decks, and podcasts. Alchemy indexes and stores the library on your Mac.

01 / Models

Use existing subscriptions and local models.

Alchemy connects to Claude Code, Codex, Gemini CLI, Copilot, Cursor, and other subscriptions you already use. It also supports 30+ gateways, OpenAI-compatible endpoints, Ollama, LM Studio, and Apple’s on-device model. Switch models mid-thread; Alchemy labels each response with its provider.

02 / Sources

Sources keep their structure and stay current.

Add a Git repository or local checkout without flattening it into uploaded text. Alchemy embeds documentation, keeps code available for exact search, and re-syncs with your existing Git credentials. PDFs, Office files, folders, and cloud drives belong in the same notebook.

03 / Retrieval

Evidence you can open.

Alchemy combines semantic similarity with BM25 exact-match search. Each citation opens the source at the highlighted passage. Deep Research runs additional searches for harder questions, while Ask Everything searches across notebooks.

Hybrid searchTested from 1M to 10M characters

04 / Studio

Create documents, decks, quizzes, and podcasts.

Create editable documents, 16:9 slide decks, quizzes, mind maps, and tables from the latest notebook sources. Audio Overview writes a two-host script with your chosen chat model and runs Kokoro speech synthesis on your Mac.

Editable outputNative PDF export

05 / Agents

Give agents access to the same notebook.

The localhost MCP server lets Codex, Claude Code, Gemini CLI, and other agents search notebooks, add sources, and write notes. Their changes appear in Alchemy as they work, so you do not need to copy context between apps.

Localhost only
Embeddings Database On your Mac no account · no server
06 / Privacy

Your library stays on your Mac.

Alchemy extracts, chunks, embeds, and stores sources on your Mac. It sends only the chat context to the model provider you select. Choose Ollama or Apple’s on-device model to keep chat offline too.
