## Highlights

- **Lower memory use while browsing.** PDF pages release their images when they leave the reading area. Note lists retain metadata and load full bodies when needed. Web gallery images become small thumbnails before reaching the window, and graph caches have explicit limits.
- **Less background work.** Offscreen animations pause and resume when visible. Bursts of source and note changes share collection refreshes instead of repeatedly loading the same data.

## Fixes

- Scrolling inside diagrams, editors, and scrollable content no longer triggers page navigation. Swipe momentum advances one item per gesture.
- Large generation prompts are delivered through standard input across CLI providers, including Copilot and Bob, instead of failing at command-line size limits.
- Daily briefs load recent reports without reading every historical note.
- UML and mind-map generation use bounded source context. Diagram jobs also have output and time limits.
- Closed diagram views release idle rendering resources.
- Note deletion reads complete undo snapshots before deleting. Redo follows the new IDs assigned to restored notes, and retrying a partial restore does not duplicate notes already recovered.

## Notes

Resource savings depend on the notebook and workload. These changes do not imply that total application memory has been halved; reproducible workload measurements are documented with the resource checks.
